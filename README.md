# Student Performance Analysis

## Project Overview
An exploratory data analysis project investigating factors associated with students' mathematics performance.

## Objectives
- Understand and inspect the dataset.
- Explore mathematics grade distribution.
- Analyse study time and academic performance.
- Investigate absences and final grades.
- Identify correlations between variables.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
UCI Machine Learning Repository – Student Performance Dataset.

Source: https://archive.ics.uci.edu/dataset/320/student+performance

## Key Findings
- Analysed 395 student records and 33 columns.
- Found no missing values or duplicate rows.
- Students studying 5–10 hours had the highest average final grade.
- G2 had the strongest positive correlation with G3.
- Previous failures had the strongest negative correlation with G3.

## Limitations
- Dataset represents two Portuguese schools.
- Findings may not generalise to other populations.
- Correlation does not establish causation.
